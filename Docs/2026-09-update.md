# DriftOcean 2026年9月アップデート

2026年9月10日版の依頼書を基準に、プランクトン、小魚、ハイスコア欄の名前変更、名前のNGワードフィルターを追加しました。指定された `plankton.png` と `kozakana.png` をそのまま使用しています。

## プレイ中の動作

プランクトンは流木と同じ速度倍率で右から左へ流れ、単体または3〜7個の列で出現します。序盤の出現間隔は約0.65秒で、1990年には約1.5秒、2050年以降は約4秒に減少します。取得すると小さく消える演出と、水滴に近い短い取得音が鳴ります。生成したプランクトンは再利用するため、長時間プレイでも不要なオブジェクトが増え続けません。

取得数はプレイ中には表示せず、既存のゲームオーバー／コンテニュー画面に `PLANKTON × 数` と表示します。現行ゲームには独立したクリア画面やクリア条件がないため、既存の終了画面に接続しています。

100個取得するごとに小魚が1匹、画面の左から泳いで合流し、最大3匹まで増えます。プレイヤーの過去の位置を少し遅れて追い、左上・左・左下の隊列を作ります。小魚自身が障害物に触れるとその個体が離脱し、生き残った魚が前の位置へ詰めます。中央の魚だけが残った場合は左上へ移動します。

小魚は残機・バリア・プランクトンの回収役ではなく、スコアにも影響しません。プレイヤーが障害物に当たれば通常どおりゲームオーバーです。小魚は結果画面が出てから少し留まり、その後左へ反転して退場します。この演出はゲーム時間が停止していても進みます。

| 操作・状況 | 取得数 | 小魚 |
| --- | --- | --- |
| リトライ・新しいプレイ | 0に戻る | 0匹に戻る |
| コンテニュー | 引き継ぐ | 退場した魚は復活せず、次の100個の区切りで追加 |
| 小魚が障害物に当たる | 変わらない | 当たった個体だけ離脱 |
| 3匹の状態で100個の区切りに到達 | 加算する | 3匹のまま。追加分の貯め置きはしない |

## Unityで調整する設定

`Assets/Scriptable/OceanLife/OceanLifeSettings.asset` を選ぶと、出現間隔のカーブ、列の個数・間隔、漂う速さ、小魚の位置・追従の遅れ・退場速度をInspectorで変更できます。カーブの横軸は年、縦軸は出現間隔の秒数です。

色の初期比率は依頼書どおりです。

| 色 | 比率 |
| --- | ---: |
| 白・透明 | 40% |
| 黄緑 | 20% |
| 水色 | 15% |
| 黄色 | 8% |
| オレンジ | 5% |
| 茶色 | 3% |
| 紫 | 4% |
| ピンク | 5% |

素材は `Assets/Sprites/OceanLife/`、Prefabは `Assets/Prefabs/OceanLife/`、取得音は `Assets/Audios/plankton_pop.wav` にあります。画像は元ファイルとのSHA-256一致を確認し、Pointフィルター・16 pixels per unit・非圧縮のSpriteとしてインポートしています。

Mainシーンの `OceanLifeManager` は設定・Prefab・プレイヤー・カメラを参照しています。通常は追加のセットアップ操作は不要です。

## 名前とランキング

名前変更時、ハイスコア欄は現在の名前へ即座に更新します。ランキング一覧に登録済みの名前・スコア・スキンの記録は名前変更では更新しません。保存に失敗した場合、変更前の名前に戻します。

NGワードは `Assets/Resources/PlayerNameFilter.asset` の `Blocked Words` に登録しています。Inspectorで配列の要素を増やすと追加できます。反映にはアプリの再ビルド・配布が必要です。

指定15語のほか、大小文字、全角英字、空白・記号・ゼロ幅文字を挟んだ表記も同じ語として判定します。初期設定は部分一致です。`Match Inside English Words` を無効にすると、英語は単語単位の判定になり、`peacock` や `grape` のように禁止語が別の単語の一部に含まれる名前を許可できます。

禁止語を入力すると説明を表示して入力画面に留まります。入力UI、保存処理、スコア送信前に対処し、以前から存在する禁止名は表示時に `player` に置き換えます。過去のランキングの保存データそのものは書き換えません。

このフィルターはアプリ側のリストによる処理です。UGSのサーバー設定やCloud Codeは変更していません。

## 確認方法

Unity Test RunnerのEditModeで `SeptemberUpdateTests` を実行できます。5件のテストで100個ごとの追加と上限、色の比率、NGワード・表記ゆれ・追加可能性、Spriteと当たり判定を確認します。

Unityメニュー `DriftOcean > September Update > Run Main Scene Integration Checks` で、実際のMainシーンを使った一連の動作確認を実行できます。テスト中はUGS通信と広告SDKの起動を止め、実データに結果を送信しません。検証に使ったPlayerPrefsは終了時に元へ戻します。

取得時の物理判定、小魚の追従と個別衝突、中央の魚の移動、補充、停止中の退場、コンテニュー・リトライ、名前の即時更新と過去名保持、NG入力と画面内の表示を確認します。結果と画面画像は `Builds/SeptemberUpdate/QA/` に出力します。

実機の操作感、端末別の表示、UGSへの実通信は別途実機で確認してください。

## BGMと容量比較

通常のプロジェクトではBGMを維持しています。序盤BGMは `wondrous-waters_3 1.mp3` です。

Unityメニュー `DriftOcean > September Update > Build Android BGM Size Comparison` は、同じAndroid設定で通常版と序盤BGMのみを除外した比較版を出力します。比較用の除外はビルド中のシーンコピーだけに適用します。元の音楽ファイルやPrefabの参照は削除しません。

実測結果はビルド出力の `容量比較.md` を参照してください。AABファイルサイズは、端末がGoogle Playからダウンロードする容量やインストール後の容量とは異なります。
