=================================================================
  Unity Gaming Services (UGS) セットアップガイド
=================================================================

このガイドでは、Drift OceanにUGSを統合する手順を説明します。
UGSを使うことで、オンラインランキング、クラウドセーブ、プレイヤー認証が実現できます。

=================================================================
【1】Unity Gaming Services パッケージのインストール
=================================================================

ステップ1: Package Managerを開く
-----------------------------------
1. Unity エディタで `Window` > `Package Manager` を開く
2. 左上の「Packages:」で「Unity Registry」を選択

ステップ2: 必要なパッケージをインストール
-----------------------------------
以下のパッケージを検索してインストール：

□ **Authentication** (必須)
  - パッケージ名: com.unity.services.authentication
  - プレイヤーの認証（匿名ログイン）

□ **Cloud Save** (必須)
  - パッケージ名: com.unity.services.cloudsave
  - スキン、プレイヤー名、統計データの保存

□ **Leaderboards** (必須)
  - パッケージ名: com.unity.services.leaderboards
  - オンラインランキング

=================================================================
【2】Unity プロジェクトをUGSにリンク
=================================================================

ステップ1: Unity プロジェクトIDを作成
-----------------------------------
1. Unity エディタで `Edit` > `Project Settings` を開く
2. 左側のメニューから `Services` を選択
3. 「Create Unity Project ID」をクリック
4. Organization を選択（個人なら自分の名前でOK）
5. プロジェクトIDが作成されます

ステップ2: UGSダッシュボードを開く
-----------------------------------
1. `Project Settings` > `Services` で「Go to Dashboard」をクリック
2. Unity Cloud のダッシュボードが開きます
3. プロジェクト名「driftocean2D」が表示されていることを確認

=================================================================
【3】Leaderboard の設定
=================================================================

ステップ1: Leaderboards を有効化
-----------------------------------
1. UGS ダッシュボードで左メニューから `Leaderboards` を選択
2. 「Get Started」または「Enable」をクリック

ステップ2: Leaderboard を作成
-----------------------------------
1. 「Create Leaderboard」をクリック
2. 以下の設定を入力：

   **Leaderboard ID:** drift_ocean_ranking
   （重要！コードと一致させる必要があります）

   **Name:** Drift Ocean Ranking
   （表示名、日本語でもOK）

   **Sort Order:** Descending (降順)
   （高いスコアが上位）

   **Update Type:** Keep Best
   （ベストスコアを保持）

   **Reset Schedule:** Never
   （リセットなし、永久ランキング）

3. 「Create」をクリック

ステップ3: メタデータを設定
-----------------------------------
Leaderboard の詳細画面で：
1. 「Metadata」タブを選択（なければスキップ）
2. 以下のメタデータを追加：
   - playerName (string)
   - skinID (string)

※メタデータはプレイヤー名とスキンIDを保存するために使用

=================================================================
【4】Cloud Save の設定
=================================================================

Cloud Saveは特別な設定不要！
-----------------------------------
- UGSダッシュボードで Cloud Save を有効化するだけでOK
- データの構造はコード側で管理します

ステップ: Cloud Save を有効化
-----------------------------------
1. UGS ダッシュボードで左メニューから `Cloud Save` を選択
2. 「Enable」をクリック

これだけです！

=================================================================
【5】Unity プロジェクトでの設定
=================================================================

ステップ1: Scripting Define Symbols の追加
-----------------------------------
1. `Edit` > `Project Settings` > `Player`
2. `Other Settings` > `Scripting Define Symbols`
3. `UNITY_UGS` を追加
4. Apply をクリック

ステップ2: UGSマネージャーをシーンに配置
-----------------------------------
1. Title シーンを開く
2. Hierarchy で空の GameObject を3つ作成：
   - `UGSManager`
   - `UGSCloudSaveManager`
   - `UGSLeaderboardManager`

3. それぞれに対応するスクリプトをアタッチ：
   - UGSManager.cs
   - UGSCloudSaveManager.cs
   - UGSLeaderboardManager.cs

4. **UGSLeaderboardManager** の Inspector で：
   - `Leaderboard Id` に `drift_ocean_ranking` と入力
   （ダッシュボードで作成したIDと一致させる）

ステップ3: Game シーンにも配置（オプション）
-----------------------------------
- DontDestroyOnLoad されるので、Title シーンのみでOK
- ただし、各シーンで独立して動作させたい場合は配置してください

=================================================================
【6】テスト方法
=================================================================

エディタでのテスト
-----------------------------------
1. Play ボタンを押す
2. Console で以下のログを確認：
   ✓ "Initializing Unity Gaming Services..."
   ✓ "Unity Gaming Services initialized successfully!"
   ✓ "Sign in successful! Player ID: xxxxx"
   ✓ "Player data loaded: Name=プレイヤー, Skins=1"

エラーが出る場合：
-----------------------------------
- パッケージが正しくインストールされているか確認
- `UNITY_UGS` が Scripting Define Symbols に追加されているか確認
- プロジェクトIDが作成されているか確認

実機でのテスト
-----------------------------------
1. ビルドして実機で実行
2. ゲームオーバー後、スコアが送信されるか確認
3. UGS ダッシュボードで Leaderboards を確認
4. スコアが表示されていれば成功！

=================================================================
【7】データの流れ
=================================================================

ゲーム起動時:
-----------------------------------
1. UGSManager が初期化される
2. 匿名認証でサインイン（自動）
3. Player ID が発行される
4. Cloud Save からデータをロード
   - プレイヤー名
   - 解放済みスキン
   - 統計データ

ゲームプレイ中:
-----------------------------------
1. スキンを解放 → Cloud Save に保存
2. プレイヤー名を変更 → Cloud Save に保存

ゲームオーバー時:
-----------------------------------
1. 統計データを更新 → Cloud Save に保存
2. スコアを Leaderboard に送信
   - プレイヤー名とスキンIDをメタデータとして送信

ランキング画面:
-----------------------------------
1. Leaderboard からTop 10を取得
2. プレイヤー名とスキンIDを表示

=================================================================
【8】セキュリティについて
=================================================================

現在の実装の安全性:
-----------------------------------
✅ スキン解放状態はサーバー（Cloud Save）に保存
✅ ランキングスコアはサーバー（Leaderboards）に保存
✅ プレイヤー名はサーバー（Cloud Save）に保存
⚠️ スキン解放条件のチェックはクライアント側

完全にチート不可にするには:
-----------------------------------
- Cloud Code（サーバー側ロジック）を使用
- スキン解放条件をサーバー側で検証
- ただし、実装が複雑になります

通常のモバイルゲームでは現在の実装で十分です。

=================================================================
【9】制限事項
=================================================================

無料プランの制限:
-----------------------------------
- Cloud Save: 1ユーザーあたり 5KB まで
- Leaderboards: 無制限（基本的に）
- 同時接続数: 50 CCU (Concurrent Users)

現在の実装での使用量:
-----------------------------------
- PlayerCloudData: 約 1KB 未満
- 十分に無料枠内で運用可能

有料プランが必要になるケース:
-----------------------------------
- 大量のデータ保存（セーブデータが5KB超える）
- 同時接続数が50人を超える
- より高度な機能（Cloud Code等）

=================================================================
【10】トラブルシューティング
=================================================================

Q: "Failed to initialize UGS" エラーが出る
A: - プロジェクトIDが作成されているか確認
   - インターネット接続を確認
   - パッケージが正しくインストールされているか確認

Q: "Failed to sign in" エラーが出る
A: - プロジェクトIDを再作成してみる
   - Unity エディタを再起動してみる

Q: スコアがLeaderboardに表示されない
A: - Leaderboard ID が正しいか確認 (drift_ocean_ranking)
   - UGS ダッシュボードでLeaderboardが作成されているか確認
   - サインインが成功しているか Console ログで確認

Q: Cloud Save からデータがロードされない
A: - 初回は必ずデータが無いので、新規作成される
   - 2回目以降のプレイでデータが保持されているか確認
