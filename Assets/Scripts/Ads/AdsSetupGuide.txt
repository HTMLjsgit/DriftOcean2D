=================================================================
  IronSource LevelPlay 広告機能セットアップガイド
=================================================================

このガイドでは、Drift Ocean ゲームに広告機能を統合する手順を説明します。

=================================================================
【1】IronSource LevelPlay SDK のインストール
=================================================================

方法1: Unity Package Manager (推奨)
-----------------------------------
1. Unity エディタで Window > Package Manager を開く
2. 検索バーで "Ads Mediation" を検索
3. または、パッケージ名 "com.unity.services.levelplay" を入力
4. インストールボタンをクリック

方法2: .unitypackage ファイル
-----------------------------------
1. https://developers.is.com/ironsource-mobile/unity/unity-plugin/
   から "Download Unity Plugin" をクリックして .unitypackage をダウンロード
2. Unity で Assets > Import Package > Custom Package
3. ダウンロードした .unitypackage を選択してインポート

=================================================================
【2】IronSource アカウントとアプリの設定
=================================================================

1. IronSource アカウント作成
-----------------------------------
   https://platform.ironsrc.com/ でアカウントを作成

2. アプリケーションの登録
-----------------------------------
   - ダッシュボードで新しいアプリを追加
   - アプリ名: "Drift Ocean"
   - プラットフォーム: Android (iOS は後で追加可能)
   - App Key を取得（後で使用）

3. 広告ユニットの作成
-----------------------------------
   a) リワード広告ユニット
      - 名前: "RewardedAd_Continue" (コンティニュー用)
      - 名前: "RewardedAd_Skin" (スキン解放用)
      ※1つの広告ユニットを両方で使い回すことも可能

   b) インタースティシャル広告ユニット
      - 名前: "Interstitial_PlayCount" (5回ごと表示用)

   各広告ユニットの ID を控えておく

=================================================================
【3】Unity プロジェクトでの設定
=================================================================

1. AdsManager の設定
-----------------------------------
   - Hierarchy で空のGameObjectを作成
   - 名前を "AdsManager" に変更
   - AdsManager.cs スクリプトをアタッチ
   - Inspector で以下の値を設定:

     App Key: [IronSource ダッシュボードから取得した App Key]
     Rewarded Ad Unit Id: [リワード広告ユニットID]
     Interstitial Ad Unit Id: [インタースティシャル広告ユニットID]
     Ad Interval Play Count: 5 (デフォルト)

2. Scripting Define Symbols の追加
-----------------------------------
   - Edit > Project Settings > Player
   - Other Settings > Scripting Define Symbols
   - "UNITY_LEVELPLAY" を追加
   - Apply をクリック

   ※これにより、SDK がインストールされていることをコードに知らせます

3. Android の設定
-----------------------------------
   - Assets > Mobile Dependency Resolver > Android Resolver > Resolve
   - 依存関係を解決してビルドの準備

4. iOS の設定（後で対応する場合）
-----------------------------------
   - Info.plist に SKAdNetwork 設定を追加
   - App Transport Security 設定を追加
   詳細: https://developers.is.com/ironsource-mobile/unity/unity-plugin/

=================================================================
【4】シーンへの配置
=================================================================

各シーンに AdsManager を配置する方法:

方法1: DontDestroyOnLoad を使用（推奨・既に実装済み）
-----------------------------------
   - Title シーンに AdsManager を1つ配置
   - AdsManager は自動的に DontDestroyOnLoad されるため、
     シーン遷移しても消えません

方法2: 各シーンに配置
-----------------------------------
   - Title シーンと Game シーンの両方に AdsManager を配置
   - Singleton パターンにより、重複したインスタンスは自動削除されます

=================================================================
【5】広告の動作確認
=================================================================

テストモード
-----------------------------------
1. IronSource ダッシュボードでテストモードを有効化
2. テストデバイスの追加（デバイスIDを登録）
3. Unity でビルドして実機でテスト

動作確認項目:
-----------------------------------
□ ゲーム開始5回ごとにインタースティシャル広告が表示される
□ ゲームオーバー時にコンティニューボタンが表示される
□ コンティニューボタンをクリックするとリワード広告が表示される
□ 広告視聴後にゲームが復活する
□ AdWatch タイプのスキンをクリックすると広告が表示される
□ 広告視聴後にスキンが解放される

=================================================================
【6】広告の種類と使用箇所
=================================================================

1. リワード広告（Rewarded Ad）
-----------------------------------
   使用箇所:
   - ゲームオーバー時のコンティニュー（1回のみ）
   - AdWatch タイプのスキン解放

   実装場所:
   - GameOverManager.cs (コンティニュー)
   - SkinUI.cs (スキン解放)

2. インタースティシャル広告（Interstitial Ad）
-----------------------------------
   使用箇所:
   - プレイ回数5回ごとに自動表示

   実装場所:
   - StageManager.cs (ゲーム開始時にカウント)
   - AdsManager.cs (広告表示)

=================================================================
【7】トラブルシューティング
=================================================================

広告が表示されない場合:
-----------------------------------
1. App Key と広告ユニットIDが正しく設定されているか確認
2. Scripting Define Symbols に UNITY_LEVELPLAY が追加されているか確認
3. Console ログでエラーメッセージを確認
4. IronSource ダッシュボードでテストモードが有効になっているか確認
5. インターネット接続を確認

SDK未インストールでもコンパイルエラーにならない:
-----------------------------------
   - AdsManager.cs では #if UNITY_LEVELPLAY ディレクティブを使用
   - SDK未インストール時は広告をスキップしてゲームが動作する
   - テスト用のフォールバック処理が実装されている

=================================================================
【8】本番リリース前の確認事項
=================================================================

□ App Key と広告ユニットIDが本番用に設定されている
□ テストモードを無効化
□ 広告の表示頻度が適切か確認（5回ごとは調整可能）
□ 各種広告が正しく動作することを確認
□ プライバシーポリシーに広告使用について記載
□ GDPR/COPPA などの規制に準拠した設定
