=================================================================
  Google AdMob 広告機能セットアップガイド
=================================================================

このガイドでは、Drift Ocean ゲームにAdMob広告を統合する手順を説明します。
AdMobはGoogleが提供する広告プラットフォームで、設定が簡単です。

=================================================================
【1】Google Mobile Ads Unity Plugin のインストール
=================================================================

方法1: Unity Package Manager経由でインストール（推奨）
-----------------------------------
1. https://github.com/googleads/googleads-mobile-unity/releases
   にアクセス

2. 最新版の「GoogleMobileAds-v*.*.*.unitypackage」をダウンロード
   例: GoogleMobileAds-v9.0.0.unitypackage

3. Unity で Assets > Import Package > Custom Package

4. ダウンロードした .unitypackage を選択してインポート

5. 全てのファイルを選択して「Import」をクリック

方法2: Unity Asset Storeから（別の選択肢）
-----------------------------------
Asset StoreでもGoogle Mobile Ads SDKを検索して導入できます

=================================================================
【2】Google AdMob アカウントとアプリの設定
=================================================================

1. AdMob アカウント作成
-----------------------------------
   https://admob.google.com/ でGoogleアカウントでログイン

2. アプリケーションの追加
-----------------------------------
   - 左メニューから「アプリ」をクリック
   - 「アプリを追加」ボタンをクリック
   - 「アプリは Google Play または App Store に公開されていますか？」
     → 「いいえ」を選択（まだ公開前の場合）
   - アプリ名: 「Drift Ocean」と入力
   - プラットフォーム: 「Android」を選択
   - 「アプリを追加」をクリック

3. アプリIDを取得
-----------------------------------
   - アプリが追加されると「アプリID」が表示されます
   - 形式: ca-app-pub-1234567890123456~1234567890
   - このIDを控えておいてください

=================================================================
【3】広告ユニットの作成
=================================================================

1. リワード広告ユニットを作成
-----------------------------------
   - アプリの詳細ページで「広告ユニット」タブをクリック
   - 「広告ユニットを追加」→「リワード」を選択
   - 広告ユニット名: 「Rewarded_DriftOcean」
   - 「広告ユニットを作成」をクリック
   - **広告ユニットID** が表示されるので控える
     形式: ca-app-pub-1234567890123456/1234567890

2. インタースティシャル広告ユニットを作成
-----------------------------------
   - 同じく「広告ユニットを追加」→「インタースティシャル」を選択
   - 広告ユニット名: 「Interstitial_DriftOcean」
   - 「広告ユニットを作成」をクリック
   - **広告ユニットID** が表示されるので控える

=================================================================
【4】Unity プロジェクトでの設定
=================================================================

ステップ1: Scripting Define Symbols の追加
-----------------------------------
   - Edit > Project Settings > Player
   - Other Settings > Scripting Define Symbols
   - 「UNITY_ADMOB」を追加
   - Apply をクリック

ステップ2: AdMob App IDの設定
-----------------------------------
   - Unity メニューから Assets > Google Mobile Ads > Settings
   - 「Google AdMob」セクションの「Android」タブを選択
   - 「AdMob App ID」欄に、先ほど取得したアプリIDを入力
     例: ca-app-pub-1234567890123456~1234567890

ステップ3: AdsManager の設定
-----------------------------------
   1. Hierarchy で空の GameObject を作成
   2. 名前を「AdsManager」に変更
   3. AdsManager.cs スクリプトをアタッチ
   4. Inspector で以下の値を設定:

      ■ AdMob Settings
      - Use Test Ads: ✓（チェック）← 開発中は必須！

      ■ Ad Unit IDs (本番用)
      - Android Rewarded Ad Unit Id:
        [AdMobで作成したリワード広告ユニットID]

      - Android Interstitial Ad Unit Id:
        [AdMobで作成したインタースティシャル広告ユニットID]

      ■ Play Count Ad Settings
      - Ad Interval Play Count: 5

   ※ Use Test Ads にチェックを入れると、テスト広告が表示されます
   ※ 本番リリース時はチェックを外してください

ステップ4: Android の設定
-----------------------------------
   - Build Settings > Player Settings > Publishing Settings
   - 「Custom Main Gradle Template」を有効化（必要に応じて）
   - minSdkVersion を 21 以上に設定

=================================================================
【5】シーンへの配置
=================================================================

Titleシーンに配置（推奨）
-----------------------------------
   - Title シーンを開く
   - 上記で作成した AdsManager オブジェクトを配置
   - AdsManager は DontDestroyOnLoad されるため、
     他のシーンに遷移しても消えません

=================================================================
【6】動作確認
=================================================================

テストモードでの確認（重要！）
-----------------------------------
1. AdsManager の「Use Test Ads」にチェックが入っていることを確認

2. ビルドして実機でテスト
   - File > Build Settings
   - Platform: Android
   - Build And Run

3. 動作確認項目:
   □ ゲーム開始5回ごとにインタースティシャル広告が表示される
   □ ゲームオーバー時にコンティニューボタンが表示される
   □ コンティニューボタンで広告が表示され、視聴後に復活する
   □ AdWatchタイプのスキンをタップすると広告が表示される
   □ 広告視聴後にスキンが解放される

テスト広告の見分け方:
-----------------------------------
   - 広告の上部に「Test Ad」または「テスト広告」と表示されます
   - これが表示されていれば正しくテストモードで動作しています

=================================================================
【7】広告の種類と使用箇所
=================================================================

1. リワード広告（Rewarded Ad）
-----------------------------------
   使用箇所:
   - ゲームオーバー時のコンティニュー（1回のみ）
   - AdWatch タイプのスキン解放

   実装場所:
   - GameOverManager.cs (コンティニュー)
   - SkinUI.cs (スキン解放)

2. インタースティシャル広告（Interstitial Ad）
-----------------------------------
   使用箇所:
   - プレイ回数5回ごとに自動表示

   実装場所:
   - StageManager.cs (ゲーム開始時にカウント)
   - AdsManager.cs (広告表示)

=================================================================
【8】トラブルシューティング
=================================================================

広告が表示されない場合:
-----------------------------------
1. 「Use Test Ads」にチェックが入っているか確認
2. Scripting Define Symbols に「UNITY_ADMOB」が追加されているか確認
3. Google Mobile Ads SDK が正しくインポートされているか確認
4. Console ログでエラーメッセージを確認
5. インターネット接続を確認
6. 実機でテスト（エディタでは広告は表示されません）

「SDK is not initialized」エラーが出る:
-----------------------------------
   - Assets > Google Mobile Ads > Settings で App ID が設定されているか確認
   - App ID の形式が正しいか確認（ca-app-pub-...~...）

広告のロードに時間がかかる:
-----------------------------------
   - 初回ロード時は時間がかかることがあります
   - インターネット速度によって変わります
   - ログで「Ad loaded successfully」を確認してください

=================================================================
【9】本番リリース前の確認事項
=================================================================

必須チェック項目:
-----------------------------------
□ AdsManager の「Use Test Ads」のチェックを**外す**
□ 広告ユニットIDが本番用のIDに設定されている
□ AdMob App ID が正しく設定されている
□ 各種広告が正しく動作することを実機で確認
□ プライバシーポリシーに広告使用について記載
□ Google Play のポリシーに準拠しているか確認

重要: Use Test Ads を外し忘れると収益が発生しません！

【12】よくある質問
=================================================================

Q: エディタで広告をテストできますか？
A: いいえ。AdMobの広告は実機でのみ動作します。

Q: iOSにも対応できますか？
A: はい。App Store に公開後、AdMobでiOSアプリを追加し、
   iOS用の広告ユニットIDを設定すれば対応できます。

Q: 広告の表示頻度を変更できますか？
A: はい。AdsManager の「Ad Interval Play Count」の値を変更してください。
   デフォルトは5回ごとです。

Q: テスト広告をクリックしても大丈夫ですか？
A: はい。テスト広告は何度クリックしても問題ありません。

Q: 本番広告を開発中に使ってもいいですか？
A: 絶対にダメです！自分の広告をクリックすると、
   AdMobアカウントが停止される可能性があります。
   必ず「Use Test Ads」を使用してください。
